# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository. Only the GYNX.GG team can see these reports.

Please include:

- what you found and where (file, endpoint or command)
- steps to reproduce
- the impact you expect

We aim to acknowledge reports within a few days. Reporting a vulnerability does not grant permission to use the software (see [LICENSE](LICENSE)). Do not test against GYNX.GG's live services, servers or members.

## Scope

This repository contains no credentials or customer data. All secrets are supplied at deploy time. If you find something that looks like a real secret in this repository or its history, report it privately as above.

For how the software protects data, see [docs/security.md](docs/security.md).
